# Qz-UILib Platform 5.0.0-beta3

基于 `5.0.0-beta2` 的预发布更新。本次更新使桌面与嵌入式宿主全面接入新版后台配置与字体准备流程，修正了外部光影字体管线的输出目标保持与缓冲游标问题，并改善了 HLS 流媒体在直播与 B 帧场景下的定位准确性。

## 主要更新

### 宿主状态与输入边界

- **后台 I/O 与生命周期结算**：桌面与嵌入式宿主复用新版配置文档与字体准备能力，由后台负责 I/O，所属 owner 与状态域负责资源发布、失败处理与关闭结算。
- **就绪状态与修饰键统一**：桌面就绪状态与页面实际装配完成严格对齐，统一 `Primary` 修饰键的输入边界。

### 图形管线与光影支持

- **共享 GL 可见性**：共享 GL 的准备与回放阶段采用一致的可见性判断标准。
- **外部字体管线修复**：修正外部字体 pass 的实际输出目标保持逻辑，以及光影属性名称查询的缓冲游标，供已接入的 Angelica / Iris 调用链使用（#74）；具体第三方 Mod 的 ABI 适配由独立组件 `Qz-UILib-Compat` 承载。

### 流媒体播放（HLS）

- **请求与片段关联**：修正 HLS 的 program、播放列表响应、URI/Range 与片段身份关联逻辑。
- **首包保留与定位校准**：使用实际首 DTS 校准定位并保留首包，改善直播窗口及含 B 帧片段的定位正确性。

## 升级或安装说明

- **版本同步**：请将 Core、Platform、Minecraft 整组同步升级至 `5.0.0-beta3`，避免与旧版本混用。
- **接入方式**：Maven Group ID 继续为 `asia.quanhuzeyu.uilib`，Java 8 环境请使用对应的 `java8` classifier；离线接入请使用同版本 Maven ZIP。
- **开源许可**：项目自有代码继续采用 MIT 许可证，第三方组件保留各自原有许可。
