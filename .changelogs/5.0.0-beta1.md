# Qz-UILib-Platform 5.0.0-beta1

UILib 5.0 拆分为三个独立仓库：`Qz-UILib-Platform` 维护字体、GL 渲染、LWJGL 绑定、媒体与桌面宿主，核心归 `Qz-UILib-Core`，Minecraft 宿主归 `Qz-UILib`。
本版为 `5.0.0-beta1` 预发布；自有代码采用 MIT 许可证，第三方组件保留原许可。

## 主要变化

- **字体与 GL 渲染适配**：提供 `font-adapter` 真实字体整形光栅、`gl-renderer` 共享 OpenGL 回放，以及 `lwjgl2-adapter` / `lwjgl3-adapter` 双 Java 目标产物（Java 21 与 `:java8`）。
- **媒体解码与播放**：`media-adapter` 支持本地音视频、HTTP/HLS 点播直播与 Bilibili 公开源播放，当前随包媒体原生库重点面向 Windows。
- **独立桌面宿主**：提供 Java 21 单窗口 `desktop` 与 `desktop-dist` 发行包，无需安装 Minecraft 即可运行配置页或自定义页面；`platform-verification` 独立发布。

## 获取与接入

- **Maven 坐标**：5.0 公开坐标为 `asia.quanhuzeyu.uilib:<模块>:5.0.0-beta1`（Java 8 附加 `:java8`，Java 包名不变，旧 group 仅用于 `4.x`）。
- **离线 ZIP 与桌面启动**：可将同版本 Core 与 Platform 的 Maven ZIP 解压至同一目录并用 `-PuilibRepository=<本地目录>` 消费；桌面用户解压 `desktop-dist` 后用 Java 21 启动：Windows 使用 `bin/qz-desktop.bat`，Unix 使用 `bin/qz-desktop.sh`。
- **宿主验证**：GPU 窗口、原生输入、音频输出及非 Windows 媒体环境需在目标设备上按实例验证。
