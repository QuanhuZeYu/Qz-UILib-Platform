# Qz-UILib Platform 5.0.0-beta2

本版使字体与桌面产物独立携带完整 native 许可，并沿用同版本 Core。

## 修复

- font-adapter 两个 Java 目标、desktop、相应 sources 与 desktop-dist 随附 LWJGL 3.4.2 BSD、FreeType FTL 与 FreeType Team 致谢、HarfBuzz 14.2.1 Old MIT 和文件/Unicode 数据级附加通知。
- 许可与版本来源位于 assets/qz_uilib/licenses/native/；desktop-dist 解压后可直接读取 licenses/native/。
- media-adapter 继续在原 assets/qz_uilib/licenses/media/ 交付全文、清单、精确源码、重建与动态库替换说明；桌面分发可直接读取 licenses/media/。
- 实际 JAR、sources 和 dist 的产物检查覆盖新增材料。

## 接入

将 Core 与 Platform 升级至同一 5.0.0-beta2；Maven group 为 asia.quanhuzeyu.uilib，Java8 选择 java8 classifier。离线接入将两份同版本 Maven ZIP 解压到同一目录。原 beta1 的许可补充包位于其原 Release。

## 验证范围

完整 build 覆盖字体、GL、媒体、桌面与独立验证消费者；窗口、设备和游戏交互需按目标环境验证。实际提交、发布运行与资产见下方构建证据。
